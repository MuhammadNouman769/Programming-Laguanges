Introduction

What is Data Structures & Algorithms?

🧠 DSA in Simple Words

Data Structures are ways to organize and store data efficiently. Algorithms are step-by-step procedures to solve problems.

Think of it like this: Data structures are like different types of containers (boxes, shelves, files), and algorithms are like the methods to organize and find things in these containers.

📦 Data Structures

How to store data:

  • Arrays — simple list
  • Linked Lists — flexible chain
  • Trees — hierarchical
  • Graphs — networked

⚙️ Algorithms

How to process data:

  • Sorting — arrange data
  • Searching — find data
  • Dynamic Programming — optimize
  • Graph algorithms — navigate networks

Complexity Analysis

Time & Space Complexity

Complexity analysis helps us understand how efficient an algorithm is. It's measured in terms of time (how fast) and space (how much memory).

Big O Notation

Big O describes the worst-case scenario. It tells us how the runtime grows as input size grows.

NotationNameExample
O(1)ConstantAccessing array element
O(log n)LogarithmicBinary search
O(n)LinearLoop through array
O(n log n)LinearithmicMerge sort, Quick sort
O(n²)QuadraticNested loops (Bubble sort)
O(2^n)ExponentialRecursive Fibonacci (naive)
O(n!)FactorialTraveling Salesman (naive)
# O(1) — Constant Time def get_first(arr): return arr[0] # Always takes the same time # O(n) — Linear Time def find_max(arr): max_val = arr[0] for num in arr: # Runs n times if num > max_val: max_val = num return max_val # O(n²) — Quadratic Time def print_pairs(arr): for i in range(len(arr)): for j in range(len(arr)): # Nested loop print(arr[i], arr[j])
💡
Space Complexity: Similar to time complexity, but measures memory usage. For example, creating a new array of size n adds O(n) space.

Arrays & Lists

Arrays in Python

Python's list is a dynamic array that can grow and shrink as needed.

# Creating arrays arr = [1, 2, 3, 4, 5] arr = list(range(5)) # [0, 1, 2, 3, 4] # Accessing elements arr[0] # First element arr[-1] # Last element # Slicing arr[1:4] # [2, 3, 4] arr[::2] # [1, 3, 5] — every 2nd element # Operations arr.append(6) # Add to end — O(1) arr.insert(0, 0) # Insert at index — O(n) arr.pop() # Remove from end — O(1) arr.pop(0) # Remove from start — O(n) arr.remove(3) # Remove first 3 — O(n) arr.index(5) # Find index — O(n) arr.sort() # Sort — O(n log n) arr.reverse() # Reverse — O(n)

✅ Advantages

  • Fast random access O(1)
  • Cache-friendly
  • Simple to use

❌ Disadvantages

  • Insert/delete at start O(n)
  • Fixed size (in some languages)
  • Memory fragmentation

Linked List

Singly Linked List

A linked list is a linear data structure where elements are stored in nodes, each pointing to the next node.

class Node: def __init__(self, data): self.data = data self.next = None class LinkedList: def __init__(self): self.head = None def append(self, data): # O(n) new_node = Node(data) if self.head is None: self.head = new_node return last = self.head while last.next: last = last.next last.next = new_node def prepend(self, data): # O(1) new_node = Node(data) new_node.next = self.head self.head = new_node def delete(self, key): # O(n) current = self.head if current and current.data == key: self.head = current.next return prev = None while current and current.data != key: prev = current current = current.next if current is None: return prev.next = current.next def display(self): current = self.head while current: print(current.data, end=" -> ") current = current.next print("None")

✅ Advantages

  • Dynamic size
  • Fast insert/delete at start O(1)
  • No memory wastage

❌ Disadvantages

  • No random access O(n)
  • Extra memory for pointers
  • Not cache-friendly

Stack

LIFO — Last In, First Out

A stack follows LIFO principle. Think of a stack of plates — you add to the top and remove from the top.

class Stack: def __init__(self): self.items = [] def push(self, item): # O(1) self.items.append(item) def pop(self): # O(1) if not self.is_empty(): return self.items.pop() def peek(self): # O(1) if not self.is_empty(): return self.items[-1] def is_empty(self): return len(self.items) == 0 def size(self): return len(self.items)

Queue

FIFO — First In, First Out

A queue follows FIFO principle. Think of a ticket counter line — first person in line gets served first.

class Queue: def __init__(self): self.items = [] def enqueue(self, item): # O(1) self.items.append(item) def dequeue(self): # O(n) — inefficient! if not self.is_empty(): return self.items.pop(0) def front(self): if not self.is_empty(): return self.items[0] def is_empty(self): return len(self.items) == 0
# Better implementation using collections.deque from collections import deque class Queue: def __init__(self): self.items = deque() def enqueue(self, item): # O(1) self.items.append(item) def dequeue(self): # O(1) if not self.is_empty(): return self.items.popleft() def front(self): if not self.is_empty(): return self.items[0] def is_empty(self): return len(self.items) == 0

Recursion

Function Calling Itself

Recursion is when a function calls itself. Every recursive function needs:

  • Base case — when to stop
  • Recursive case — when to call itself
# Factorial using recursion def factorial(n): if n <= 1: # Base case return 1 return n * factorial(n - 1) # Recursive case # Fibonacci using recursion def fibonacci(n): if n <= 1: # Base case return n return fibonacci(n - 1) + fibonacci(n - 2) # Recursive # Recursive traversal def traverse(node): if node is None: # Base case return print(node.data) traverse(node.left) # Recursive traverse(node.right) # Recursive
⚠️
Stack Overflow: Recursion uses the call stack. Deep recursion may cause stack overflow. Use iterative solutions for very deep recursion.

Sorting Algorithms

Popular Sorting Algorithms

# Bubble Sort — O(n²) def bubble_sort(arr): n = len(arr) for i in range(n): for j in range(0, n - i - 1): if arr[j] > arr[j + 1]: arr[j], arr[j + 1] = arr[j + 1], arr[j] return arr # Selection Sort — O(n²) def selection_sort(arr): n = len(arr) for i in range(n): min_idx = i for j in range(i + 1, n): if arr[j] < arr[min_idx]: min_idx = j arr[i], arr[min_idx] = arr[min_idx], arr[i] return arr
# Merge Sort — O(n log n) def merge_sort(arr): if len(arr) <= 1: return arr mid = len(arr) // 2 left = merge_sort(arr[:mid]) right = merge_sort(arr[mid:]) return merge(left, right) def merge(left, right): result = [] i = j = 0 while i < len(left) and j < len(right): if left[i] <= right[j]: result.append(left[i]) i += 1 else: result.append(right[j]) j += 1 result.extend(left[i:]) result.extend(right[j:]) return result # Quick Sort — O(n log n) average def quick_sort(arr): if len(arr) <= 1: return arr pivot = arr[len(arr) // 2] left = [x for x in arr if x < pivot] middle = [x for x in arr if x == pivot] right = [x for x in arr if x > pivot] return quick_sort(left) + middle + quick_sort(right)

Searching Algorithms

Linear & Binary Search

# Linear Search — O(n) def linear_search(arr, target): for i, val in enumerate(arr): if val == target: return i return -1 # Binary Search — O(log n) — requires sorted array def binary_search(arr, target): left, right = 0, len(arr) - 1 while left <= right: mid = (left + right) // 2 if arr[mid] == target: return mid elif arr[mid] < target: left = mid + 1 else: right = mid - 1 return -1 # Binary Search (recursive) def binary_search_recursive(arr, target, left, right): if left > right: return -1 mid = (left + right) // 2 if arr[mid] == target: return mid elif arr[mid] < target: return binary_search_recursive(arr, target, mid + 1, right) else: return binary_search_recursive(arr, target, left, mid - 1)

Tree Data Structure

A tree is a hierarchical data structure with a root node and child nodes. Each node has a parent (except root) and zero or more children.

class TreeNode: def __init__(self, data): self.data = data self.children = [] # Creating a tree root = TreeNode("A") child1 = TreeNode("B") child2 = TreeNode("C") child3 = TreeNode("D") root.children.extend([child1, child2, child3]) child1.children.append(TreeNode("E")) child1.children.append(TreeNode("F"))

Binary Tree

A binary tree is a tree where each node has at most 2 children (left and right).

class BinaryTreeNode: def __init__(self, data): self.data = data self.left = None self.right = None # Creating a binary tree root = BinaryTreeNode(1) root.left = BinaryTreeNode(2) root.right = BinaryTreeNode(3) root.left.left = BinaryTreeNode(4) root.left.right = BinaryTreeNode(5) # 1 # / \ # 2 3 # / \ # 4 5
Chapter 10

Binary Search Tree (BST)

BST — Sorted Binary Tree

A BST is a binary tree where:

  • All nodes in the left subtree are less than the node
  • All nodes in the right subtree are greater than the node
class BSTNode: def __init__(self, data): self.data = data self.left = None self.right = None class BST: def __init__(self): self.root = None def insert(self, data): if self.root is None: self.root = BSTNode(data) else: self._insert_recursive(self.root, data) def _insert_recursive(self, node, data): if data < node.data: if node.left is None: node.left = BSTNode(data) else: self._insert_recursive(node.left, data) else: if node.right is None: node.right = BSTNode(data) else: self._insert_recursive(node.right, data) def search(self, data): return self._search_recursive(self.root, data) def _search_recursive(self, node, data): if node is None or node.data == data: return node if data < node.data: return self._search_recursive(node.left, data) return self._search_recursive(node.right, data) # Usage bst = BST() bst.insert(5) bst.insert(3) bst.insert(7) bst.insert(2) bst.insert(4) bst.insert(6) bst.insert(8)

Tree Traversals

DFS & BFS Traversals

# Preorder: Root → Left → Right def preorder(node): if node is None: return print(node.data, end=" ") preorder(node.left) preorder(node.right) # Inorder: Left → Root → Right (gives sorted order for BST) def inorder(node): if node is None: return inorder(node.left) print(node.data, end=" ") inorder(node.right) # Postorder: Left → Right → Root def postorder(node): if node is None: return postorder(node.left) postorder(node.right) print(node.data, end=" ") # BFS / Level Order from collections import deque def level_order(root): if root is None: return queue = deque([root]) while queue: node = queue.popleft() print(node.data, end=" ") if node.left: queue.append(node.left) if node.right: queue.append(node.right) # For the tree: # 1 # / \ # 2 3 # / \ # 4 5 # Preorder: 1 2 4 5 3 # Inorder: 4 2 5 1 3 # Postorder: 4 5 2 3 1 # Level: 1 2 3 4 5

Heaps

Heap Data Structure

A heap is a complete binary tree that satisfies the heap property:

  • Max Heap: Parent ≥ Children
  • Min Heap: Parent ≤ Children
import heapq # Min Heap (default) heap = [] heapq.heappush(heap, 5) heapq.heappush(heap, 3) heapq.heappush(heap, 8) heapq.heappush(heap, 1) print(heap[0]) # 1 (smallest) heapq.heappop(heap) # Removes 1 print(heap[0]) # 3 # Max Heap (using negative values) max_heap = [] heapq.heappush(max_heap, -5) heapq.heappush(max_heap, -3) heapq.heappush(max_heap, -8) heapq.heappush(max_heap, -1) print(-max_heap[0]) # 8 (largest) # Heapify an existing list arr = [5, 3, 8, 1] heapq.heapify(arr) print(arr) # [1, 3, 8, 5] # nlargest / nsmallest print(heapq.nlargest(2, arr)) # [8, 5] print(heapq.nsmallest(2, arr)) # [1, 3]

Hashing

Hash Tables / Dictionaries

Hashing provides O(1) average time for insert, delete, and search operations.

# Python dictionaries are hash tables # Creating a dictionary hash_table = {} hash_table = {"name": "Akarsh", "age": 20} # Insert/Update — O(1) hash_table["city"] = "Indore" hash_table["age"] = 21 # Lookup — O(1) print(hash_table["name"]) # Akarsh print(hash_table.get("city")) # Indore # Delete — O(1) del hash_table["age"] # Iterating for key, value in hash_table.items(): print(key, value) # Check existence if "name" in hash_table: print("Name exists!")

✅ Advantages

  • O(1) average time operations
  • Simple key-value mapping
  • Dynamic resizing

❌ Disadvantages

  • Collisions possible
  • Unordered
  • Memory overhead

Graphs

Graph Representations

A graph is a collection of nodes (vertices) connected by edges.

# Adjacency List class Graph: def __init__(self): self.adj_list = {} def add_vertex(self, vertex): if vertex not in self.adj_list: self.adj_list[vertex] = [] def add_edge(self, v1, v2): if v1 in self.adj_list and v2 in self.adj_list: self.adj_list[v1].append(v2) self.adj_list[v2].append(v1) # Undirected def display(self): for vertex, neighbors in self.adj_list.items(): print(f"{vertex}: {neighbors}") # Usage g = Graph() g.add_vertex("A") g.add_vertex("B") g.add_vertex("C") g.add_vertex("D") g.add_edge("A", "B") g.add_edge("A", "C") g.add_edge("B", "D") g.add_edge("C", "D")

📋 Graph Types

  • Directed — edges have direction
  • Undirected — edges are bidirectional
  • Weighted — edges have weights
  • Cyclic — contains cycles
  • Acyclic — no cycles

📊 Representations

  • Adjacency List — O(V+E) space
  • Adjacency Matrix — O(V²) space
  • Edge List — O(E) space

Graph Traversals

BFS & DFS on Graphs

from collections import deque # BFS — Breadth First Search def bfs(graph, start): visited = set() queue = deque([start]) visited.add(start) while queue: vertex = queue.popleft() print(vertex, end=" ") for neighbor in graph.adj_list[vertex]: if neighbor not in visited: visited.add(neighbor) queue.append(neighbor) # DFS — Depth First Search (Recursive) def dfs(graph, start, visited=None): if visited is None: visited = set() visited.add(start) print(start, end=" ") for neighbor in graph.adj_list[start]: if neighbor not in visited: dfs(graph, neighbor, visited) # DFS — Iterative (using stack) def dfs_iterative(graph, start): visited = set() stack = [start] while stack: vertex = stack.pop() if vertex not in visited: visited.add(vertex) print(vertex, end=" ") for neighbor in graph.adj_list[vertex]: if neighbor not in visited: stack.append(neighbor)

Dynamic Programming

DP — Optimize Recursion

Dynamic Programming solves problems by breaking them down into smaller subproblems and storing the results to avoid recomputation.

# Fibonacci with DP (Memoization) def fib_memo(n, memo={}): if n in memo: return memo[n] if n <= 1: return n memo[n] = fib_memo(n - 1) + fib_memo(n - 2) return memo[n] # Fibonacci with DP (Tabulation) def fib_tab(n): if n <= 1: return n dp = [0] * (n + 1) dp[0] = 0 dp[1] = 1 for i in range(2, n + 1): dp[i] = dp[i - 1] + dp[i - 2] return dp[n] # Climbing Stairs (LeetCode 70) # You can climb 1 or 2 steps. How many ways to reach the top? def climb_stairs(n): if n <= 2: return n dp = [0] * (n + 1) dp[1] = 1 dp[2] = 2 for i in range(3, n + 1): dp[i] = dp[i - 1] + dp[i - 2] return dp[n]

📝 Top-Down (Memoization)

  • Starts from the top
  • Uses recursion
  • Caches results

📊 Bottom-Up (Tabulation)

  • Starts from the bottom
  • Uses iteration
  • Fills DP table
