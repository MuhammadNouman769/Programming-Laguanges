Interpreted vs Compiled

⚡ Why is Python Called Interpreted?

Python is called an interpreted language because its code is executed at runtime by the Python Virtual Machine (PVM). Unlike C/C++, the entire code is not converted to machine code beforehand.

💡
Important: Python first compiles code to bytecode (.pyc files), then PVM executes that bytecode line by line. So Python is both interpreted and compiled.

📦 Interpreted

  • Line by line execution
  • Slower execution
  • Platform independent
  • Example: Python, JS

⚙️ Compiled

  • Full code compiled
  • Faster execution
  • Platform specific
  • Example: C, C++

Python کو interpreted زبان کہا جاتا ہے کیونکہ اس کا کوڈ runtime پر Python Virtual Machine (PVM) کے ذریعے execute ہوتا ہے۔ C/C++ کی طرح پورے کوڈ کو پہلے machine code میں convert نہیں کیا جاتا۔

💡
اہم بات: Python پہلے کوڈ کو bytecode (.pyc files) میں compile کرتا ہے، پھر PVM اس bytecode کو line by line execute کرتا ہے۔ اس لیے Python interpreted بھی ہے اور compiled بھی۔

📦 Interpreted

  • لائن بہ لائن execute
  • سست execution
  • پلیٹ فارم آزاد
  • مثال: Python, JS

⚙️ Compiled

  • پورا کوڈ compile ہوتا ہے
  • تیز execution
  • پلیٹ فارم مخصوص
  • مثال: C, C++

Type Casting

🔄 What is Type Casting?

Converting one data type to another is called type casting.

🤖 Implicit (Automatic)

Python automatically converts when needed.

a = 10 # int b = 3.5 # float c = a + b # 13.5 → float

🔧 Explicit (Manual)

We manually convert types.

a = "10" # str b = int(a) # 10 → int c = float(a) # 10.0 → float

ایک ڈیٹا ٹائپ کو دوسرے ڈیٹا ٹائپ میں تبدیل کرنا type casting کہلاتا ہے۔

🤖 Implicit (خودکار)

Python خود بخود convert کرتا ہے جب ضرورت ہو۔

a = 10 # int b = 3.5 # float c = a + b # 13.5 → float

🔧 Explicit (دستی)

ہم دستی طور پر conversion کرتے ہیں۔

a = "10" # str b = int(a) # 10 → int c = float(a) # 10.0 → float

Functions

🔧 What is a Function?

A function is a reusable block of code that performs a specific task.

def greet(name): return f"Hello {name}" print(greet("Nouman")) # Hello Nouman

Parameter vs Argument

📋 Parameter

Defined when declaring the function.

def add(a, b): # a, b are parameters

📦 Argument

Passed when calling the function.

add(5, 3) # 5, 3 are arguments

Types of Arguments

# 1. Positional — order matters def info(name, age): print(name, age) info("Ali", 20) # 2. Keyword — order doesn't matter info(age=20, name="Ali") # 3. Default — value preset def greet(name="Guest"): print(name) greet() # Guest # 4. Variable-length — *args, **kwargs def total(*args): return sum(args) print(total(1, 2, 3)) # 6

Function reusable code کا ایک بلاک ہے جو ایک مخصوص کام انجام دیتا ہے۔

Question 10

Scope

🎯 What is Scope?

Scope defines the accessibility (visibility) of a variable – i.e., in which parts of the program the variable can be accessed.

🔹 Local Scope

Defined inside a function, accessible only within that function.

def func(): x = 50 # Local print(x) func() # 50

🔸 Global Scope

Defined outside functions, accessible throughout the file.

x = 100 # Global def func(): print(x) func() # 100

⚠️ Global Keyword (Interview Trap)

🚨
Common Interview Question:
my_var = 10 def test(): print(my_var) # Line 1 my_var = 20 # Line 2 print(my_var) # Line 3 test()

What will be the output? → UnboundLocalError

Reason: Python sees my_var = 20 inside the function and treats it as a local variable. At Line 1, the local variable doesn't exist yet, causing an error.

Solution: Use global my_var.

Scope variable کی accessibility (visibility) define کرتا ہے – یعنی variable پروگرام کے کس حصے میں accessible ہے۔

🔹 Local Scope

Function کے اندر define ہوتا ہے، صرف اسی function کے اندر accessible۔

def func(): x = 50 # Local print(x) func() # 50

🔸 Global Scope

Function کے باہر define ہوتا ہے، پوری فائل میں accessible۔

x = 100 # Global def func(): print(x) func() # 100

⚠️ Global Keyword (انٹرویو ٹریپ)

🚨
عام انٹرویو سوال:
my_var = 10 def test(): print(my_var) # Line 1 my_var = 20 # Line 2 print(my_var) # Line 3 test()

آؤٹ پٹ کیا ہوگا؟ → UnboundLocalError

وجہ: Python function کے اندر my_var = 20 دیکھ کر اسے local variable سمجھتا ہے۔ Line 1 پر local variable موجود نہیں، اس لیے error آتا ہے۔

حل: global my_var استعمال کریں۔

Recursion

🔄 What is Recursion?

Recursion is a technique where a function calls itself to solve a problem by breaking it into smaller parts.

2 Important Parts:

  • Base case: Stopping condition
  • Recursive case: Condition to call itself
def factorial(n): if n == 1: # Base case return 1 return n * factorial(n-1) # Recursive case print(factorial(5)) # 120

Recursion وہ technique ہے جس میں ایک function خود کو call کرتا ہے کسی مسئلے کو چھوٹے حصوں میں حل کرنے کے لیے۔

2 اہم حصے:

  • Base case: رکنے کی شرط
  • Recursive case: خود کو call کرنے کی شرط
def factorial(n): if n == 1: # Base case return 1 return n * factorial(n-1) # Recursive case print(factorial(5)) # 120

== vs is

🔍 == vs is

== (Equal to)

Compares the value of two objects.

a = [1,2] b = [1,2] print(a == b) # True

is (Identity)

Compares the memory location of two objects.

a = [1,2] b = [1,2] print(a is b) # False
🎯
Interview Tip: is checks identity, == checks equality. Use is for None, True, False.

== (Equal to)

دو objects کی value compare کرتا ہے۔

a = [1,2] b = [1,2] print(a == b) # True

is (Identity)

دو objects کی memory location compare کرتا ہے۔

a = [1,2] b = [1,2] print(a is b) # False
🎯
انٹرویو ٹپ: is identity چیک کرتا ہے، == equality چیک کرتا ہے۔ None, True, False کے لیے is استعمال کریں۔
Question 14

Deep Copy vs Shallow Copy

📋 Deep Copy vs Shallow Copy

🔹 Shallow Copy

Creates a new object but shares references to nested objects. Changes in nested objects affect both.

import copy original = [[1, 2], [3, 4]] copied = copy.copy(original) original[0][0] = 99 print(copied) # [[99, 2], [3, 4]]

🔸 Deep Copy

Creates a completely independent copy of the entire object and all nested objects.

import copy original = [[1, 2], [3, 4]] copied = copy.deepcopy(original) original[0][0] = 99 print(copied) # [[1, 2], [3, 4]]

🔹 Shallow Copy

نیا object بناتی ہے لیکن nested objects کا reference share کرتی ہے۔ nested object میں تبدیلی دونوں کو affect کرتی ہے۔

import copy original = [[1, 2], [3, 4]] copied = copy.copy(original) original[0][0] = 99 print(copied) # [[99, 2], [3, 4]]

🔸 Deep Copy

پورے object اور nested objects کی مکمل علیحدہ copy بناتی ہے۔

import copy original = [[1, 2], [3, 4]] copied = copy.deepcopy(original) original[0][0] = 99 print(copied) # [[1, 2], [3, 4]]

Iterable vs Iterator

🔁 Iterable vs Iterator

📚 Iterable

An object you can loop over. Provides __iter__() method.

Examples: list, tuple, string, set, dict, range

nums = [1, 2, 3] for n in nums: # nums is iterable print(n)

🔹 Iterator

An object that returns one value at a time using next().

nums = [1, 2, 3] it = iter(nums) print(next(it)) # 1 print(next(it)) # 2

📚 Iterable

جس object پر loop کر سکتے ہیں۔ __iter__() method فراہم کرتا ہے۔

مثالیں: list, tuple, string, set, dict, range

nums = [1, 2, 3] for n in nums: # nums iterable ہے print(n)

🔹 Iterator

جو object next() کے ذریعے ایک ایک value return کرتا ہے۔

nums = [1, 2, 3] it = iter(nums) print(next(it)) # 1 print(next(it)) # 2
Question 16

Generators

⚡ Generators

A generator is a special function that uses the yield keyword and generates values one by one.

💡
Memory Optimization: Generators don't store all values in memory at once; they generate values when needed.
def gen(): yield 10 yield 20 yield 30 g = gen() print(next(g)) # 10 print(next(g)) # 20 print(next(g)) # 30

yield vs return

return

Terminates the function completely.

yield

Pauses the function and resumes on the next call.

When to Use Generators?

  • Reading large files
  • Processing large datasets
  • Memory optimization
  • Streaming data
⚠️
Important: Generators are one-time iterators. Once all values are consumed, they are exhausted and cannot be reused.

Generator ایک خاص function ہے جو yield keyword استعمال کرتا ہے اور values کو one by one generate کرتا ہے۔

💡
Memory Optimization: Generators ساری values کو ایک ساتھ memory میں store نہیں کرتے، بلکہ جب ضرورت ہوتی ہے تب generate کرتے ہیں۔
def gen(): yield 10 yield 20 yield 30 g = gen() print(next(g)) # 10 print(next(g)) # 20 print(next(g)) # 30

yield بمقابلہ return

return

Function کو مکمل طور پر ختم کر دیتا ہے۔

yield

Function کو pause کرتا ہے اور اگلی call پر وہیں سے جاری رکھتا ہے۔

Generator کب استعمال کریں؟

  • بڑی فائلیں پڑھنے کے لیے
  • بڑے ڈیٹا سیٹس process کرنے کے لیے
  • Memory optimization کے لیے
  • Streaming data کے لیے
⚠️
اہم بات: Generator one-time iterator ہے۔ جب تمام values consume ہو جائیں تو یہ ختم ہو جاتا ہے اور دوبارہ استعمال نہیں ہو سکتا۔

Decorators

🎀 Decorators

A decorator is a function that modifies or extends the functionality of another function without changing its code.

def my_decorator(func): def wrapper(): print("Start") func() print("End") return wrapper @my_decorator def say_hello(): print("Hello!") say_hello() # Start # Hello! # End

Common Uses:

  • Logging
  • Authentication
  • Authorization
  • Timing functions
  • Caching
  • Validation

Decorator ایک function ہے جو کسی دوسرے function کی functionality کو اس کے کوڈ کو تبدیل کیے بغیر modify یا extend کرتا ہے۔

def my_decorator(func): def wrapper(): print("شروع") func() print("اختتام") return wrapper @my_decorator def say_hello(): print("ہیلو!") say_hello() # شروع # ہیلو! # اختتام

عام استعمالات:

  • Logging
  • Authentication
  • Authorization
  • Timing functions
  • Caching
  • Validation

super() is used to call parent class methods or constructors from a child class.

Question 27

Association vs Aggregation

🔗 Association vs Aggregation vs Composition

🔹 Association

When one class object is related to another class object. Both can exist independently.

class Teacher: def __init__(self, name): self.name = name class Student: def __init__(self, name, teacher): self.name = name self.teacher = teacher

🔸 Aggregation (Weak HAS-A)

One class holds another class object. The child object can exist without the parent.

class Engine: def __init__(self, type): self.type = type class Car: def __init__(self, engine): self.engine = engine

🔹 Composition (Strong HAS-A)

The child object cannot exist without the parent. If the parent is destroyed, the child is also destroyed.

class Engine: def __init__(self): self.type = "V8" class Car: def __init__(self): self.engine = Engine()

🔹 Association

جب ایک class کا object دوسری class کے object سے related ہو۔ دونوں آزادانہ طور پر exist کر سکتے ہیں۔

class Teacher: def __init__(self, name): self.name = name class Student: def __init__(self, name, teacher): self.name = name self.teacher = teacher

🔸 Aggregation (کمزور HAS-A)

ایک class دوسری class کا object رکھتی ہے۔ Child object parent کے بغیر بھی exist کر سکتا ہے۔

class Engine: def __init__(self, type): self.type = type class Car: def __init__(self, engine): self.engine = engine

🔹 Composition (مضبوط HAS-A)

Child object parent کے بغیر exist نہیں کر سکتا۔ اگر parent ختم ہو جائے تو child بھی ختم ہو جاتا ہے۔

class Engine: def __init__(self): self.type = "V8" class Car: def __init__(self): self.engine = Engine()

Question 29

Synchronous vs Asynchronous

⏱️ Synchronous vs Asynchronous

🔹 Synchronous

Code executes line by line. One task must complete before the next starts. Program flow is sequential.

print("Task 1") print("Task 2") # Runs after Task 1

🔸 Asynchronous

When a task is waiting (I/O operation), the program can start another task. The application becomes more efficient.

import asyncio async def task(): await asyncio.sleep(1) print("Done")
📌
Note: In async, tasks don't run in parallel (unless using threads/processes). They run concurrently via an event loop.

🔹 Synchronous

کوڈ line by line execute ہوتا ہے۔ ایک task مکمل ہونے کے بعد ہی دوسرا task شروع ہوتا ہے۔ پروگرام کا flow sequential ہوتا ہے۔

print("Task 1") print("Task 2") # Task 1 کے بعد چلے گا

🔸 Asynchronous

جب ایک task wait (I/O operation) میں ہو تو program اس وقت دوسرا task شروع کر سکتا ہے۔ ایپلیکیشن زیادہ موثر ہوتی ہے۔

import asyncio async def task(): await asyncio.sleep(1) print("Done")
📌
نوٹ: Async میں tasks parallel نہیں چلتے (جب تک threads/processes استعمال نہ کریں)۔ یہ event loop کے ذریعے concurrently چلتے ہیں۔
