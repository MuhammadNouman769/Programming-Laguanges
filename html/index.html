Interpreted vs Compiled

🌐 Language: 🇬🇧 English

⚡ Why is Python Called Interpreted?

Python is interpreted because code executes at runtime via PVM. Python first compiles to bytecode (.pyc), then PVM executes line by line. So it's both interpreted and compiled.

📦 Interpreted

  • Line by line
  • Slower
  • Platform independent
  • Python, JS

⚙️ Compiled

  • Full compile
  • Faster
  • Platform specific
  • C, C++

Python interpreted ہے کیونکہ کوڈ runtime پر PVM کے ذریعے execute ہوتا ہے۔ پہلے bytecode (.pyc) میں compile، پھر line by line execute۔ interpreted بھی اور compiled بھی۔

📦 Interpreted

  • لائن بہ لائن
  • سست
  • پلیٹ فارم آزاد
  • Python, JS

⚙️ Compiled

  • پورا compile
  • تیز
  • پلیٹ فارم مخصوص
  • C, C++

🔗 super() & MRO

super() calls parent class methods/constructors from child.

MRO defines the order in which Python looks for methods. Class.__mro__ or Class.mro().

super() parent class کے methods/constructors کو child سے call کرتا ہے۔

class Child(Parent): def __init__(self, name, age): super().__init__(name) self.age = age

MRO ترتیب بتاتا ہے کہ Python method کہاں ڈھونڈے۔ Class.__mro__ یا Class.mro()۔

  • Uses stack memory
  • Clean for tree/graph problems

  • Constant memory
  • تیز
  • Stack overflow نہیں

DP Basics

🌐 Language: 🇬🇧 English

🧩 Dynamic Programming

Breaks problem into overlapping subproblems and stores results to avoid recomputation.

  • Memoization: Top-down (recursive + cache)
  • Tabulation: Bottom-up (iterative + table)
# Fibonacci with DP def fib(n): dp = [0] * (n + 1) dp[1] = 1 for i in range(2, n + 1): dp[i] = dp[i-1] + dp[i-2] return dp[n]

Common Problems: Knapsack, LCS, Edit Distance, Coin Change.

مسئلہ کو overlapping subproblems میں تقسیم کرتا ہے اور نتائج store کرتا ہے تاکہ دوبارہ compute نہ کرنا پڑے۔

  • Memoization: Top-down (recursive + cache)
  • Tabulation: Bottom-up (iterative + table)

💾 Caching

Django caching improves performance by storing results of expensive operations.

# settings.py CACHES = { "default": { "BACKEND": "django.core.cache.backends.redis.RedisCache", "LOCATION": "redis://127.0.0.1:6379/1", } } # views.py from django.core.cache import cache data = cache.get("key") if data is None: data = expensive_query() cache.set("key", data, 300)

🚀 Deployment

Key considerations for deploying Django applications:

  • Web Servers: Gunicorn, uWSGI, Daphne (ASGI)
  • Web Servers: Nginx, Apache
  • Environment Variables: SECRET_KEY, DEBUG, DATABASE_URL
  • Static/Media Files: collectstatic, S3/CloudFront
  • Database: PostgreSQL preferred
  • Security: HTTPS, ALLOWED_HOSTS, CORS
  • Platforms: Heroku, AWS, DigitalOcean, PythonAnywhere
📌
Always set DEBUG=False and configure ALLOWED_HOSTS in production.
