Introduction

What is HTML?

🌐 HTML in Simple Words

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes the structure of a web page using elements (tags).

Think of HTML as the skeleton of a website — it provides the basic structure. CSS adds the skin (styling), and JavaScript adds the brain (interactivity).

🏗️ HTML = Structure

Defines headings, paragraphs, lists, links, images, tables, forms — the content of the page.

🎨 CSS = Presentation

Controls colors, fonts, layout, spacing, animations — how the page looks.

📜 A Brief History

  • 1991: Tim Berners-Lee created HTML
  • 1995: HTML 2.0
  • 1997: HTML 3.2
  • 1999: HTML 4.01
  • 2014: HTML5 (the current standard)
💡
HTML5 is the latest version, introducing semantic elements, multimedia support, and APIs for modern web applications.

🖥️ How HTML Works

HTML documents are plain text files with a .html extension. Browsers read these files and render them as web pages.

<!-- This is a comment --> <!DOCTYPE html> <html> <head> <title>My Page</title> </head> <body> <h1>Hello, World!</h1> <p>This is my first HTML page.</p> </body> </html>
✅
Key Point: HTML elements are made of opening tags <tagname>, content, and closing tags </tagname>.

Chapter 01

HTML Basics

Document Structure

<!DOCTYPE html> <!-- Tells the browser this is HTML5 --> <html> <!-- Root element --> <head> <!-- Metadata (not displayed) --> <title>Page Title</title> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> </head> <body> <!-- Visible content --> <h1>Heading</h1> <p>Paragraph text</p> </body> </html>

Common HTML Elements

TagPurpose
<h1> to <h6>Headings (h1 is largest, h6 is smallest)
<p>Paragraph
<div>Generic container (block-level)
<span>Generic container (inline)
<br>Line break (self-closing)
<hr>Horizontal rule (self-closing)
⚠️
Self-Closing Tags: Tags like <br>, <hr>, <img>, and <input> don't have closing tags.
Chapter 02

Text Formatting

Text Styling Tags

<b>Bold text</b> <strong>Important text (bold + semantic)</strong> <i>Italic text</i> <em>Emphasized text (italic + semantic)</em> <u>Underlined text</u> <s>Strikethrough text</s> <mark>Highlighted text</mark> <small>Smaller text</small> <sup>Superscript</sup> — e.g., E = mc2 <sub>Subscript</sub> — e.g., H2O <code>Inline code</code> <pre>Preformatted text (preserves spaces and line breaks)</pre> <blockquote>Blockquote — long quotation</blockquote> <q>Short inline quotation</q>

✅ Semantic vs Non-Semantic

Semantic tags (like <strong> and <em>) convey meaning. Non-semantic tags (like <b> and <i>) are just for styling.

Use semantic tags for better accessibility and SEO.

📝 Example

<p> This is <strong>important</strong> and this is <em>emphasized</em>. <br> H2O is water. E = mc2. </p>

Chapter 04

Links & Images

Hyperlinks — <a> Tag

<!-- Basic link --> <a href="https://www.google.com">Go to Google</a> <!-- Link to another page on your site --> <a href="about.html">About Us</a> <!-- Open in new tab --> <a href="https://example.com" target="_blank">Open in new tab</a> <!-- Link to an email --> <a href="mailto:someone@example.com">Email me</a> <!-- Link to a phone number --> <a href="tel:+1234567890">Call us</a> <!-- Link to a specific section on the page (anchor) --> <a href="#section2">Go to Section 2</a> <!-- ... --> <h2 id="section2">Section 2</h2>

Images — <img> Tag

<!-- Basic image --> <img src="image.jpg" alt="Description of image"> <!-- With width and height --> <img src="photo.jpg" alt="A beautiful photo" width="300" height="200"> <!-- Image as a link --> <a href="https://example.com"> <img src="logo.png" alt="Logo"> </a>
⚠️
Always use alt text! It's crucial for accessibility and SEO. Screen readers use it, and it shows if the image fails to load.

Tables

Creating Tables

<table> <thead> <!-- Table header --> <tr> <!-- Table row --> <th>Name</th> <!-- Table header cell --> <th>Age</th> <th>City</th> </tr> </thead> <tbody> <!-- Table body --> <tr> <td>Akarsh</td> <!-- Table data cell --> <td>22</td> <td>Indore</td> </tr> <tr> <td>Shery</td> <td>20</td> <td>Mumbai</td> </tr> </tbody> <tfoot> <!-- Table footer (optional) --> <tr> <td colspan="3">Total: 2 people</td> </tr> </tfoot> </table>

Chapter 06

Forms

Form Basics

<form action="/submit" method="POST"> <!-- GET: data in URL (for searching) --> <!-- POST: data in request body (for sensitive data) --> <label for="name">Name:</label> <input type="text" id="name" name="name" required> <label for="email">Email:</label> <input type="email" id="email" name="email"> <label for="message">Message:</label> <textarea id="message" name="message" rows="4" cols="50"></textarea> <button type="submit">Send</button> </form>
💡
Form Attributes:
• action — where to send the data
• method — GET or POST
• name — identifies the form field
• id — connects to <label> using "for"

Chapter 08

Semantic HTML

HTML5 Semantic Elements

Semantic elements clearly describe their meaning to both the browser and the developer.

<!-- Non-semantic (just containers) --> <div class="header"></div> <span class="highlight"></span> <!-- Semantic (meaningful) --> <header> <!-- Page header / banner --> <nav> <!-- Navigation links --> <main> <!-- Main content --> <article> <!-- Self-contained content --> <section> <!-- Thematic grouping --> <aside> <!-- Sidebar / related content --> <footer> <!-- Page footer --> <!-- Other semantic elements --> <figure> <!-- Figure with caption --> <figcaption> <!-- Figure caption --> <details> <!-- Expandable details --> <summary> <!-- Summary for details --> <time> <!-- Date/time --> <mark> <!-- Highlighted text -->

✅ Benefits of Semantic HTML

  • Accessibility: Screen readers understand the structure
  • SEO: Search engines understand content better
  • Maintainability: Code is easier to read and edit
  • Future-proof: Follows web standards

📝 Example Layout

<header>Logo & Nav</header> <main> <article>Blog post</article> <aside>Sidebar</aside> </main> <footer>Copyright</footer>

Iframes & Embed

Embedding External Content

<!-- Iframe — embed another page --> <iframe src="https://www.example.com" width="600" height="400"></iframe> <!-- Embed a YouTube video --> <iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe> <!-- Embed a Google Map --> <iframe src="https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!1d..." width="600" height="450" style="border:0;" allowfullscreen="" loading="lazy"></iframe> <!-- Embed — for plugins (Flash, etc.) --> <embed src="file.pdf" type="application/pdf" width="600" height="400"> <!-- Object — fallback for embedding --> <object data="file.pdf" type="application/pdf" width="600" height="400"> <p>Your browser doesn't support PDF viewing. <a href="file.pdf">Download PDF</a></p> </object>

Chapter 12

Accessibility

Making Websites Accessible

Web accessibility means making websites usable by people with disabilities.

<!-- Use semantic HTML --> <button>Click me</button> <!-- ✅ Semantic --> <div onclick="click()">Click me</div> <!-- ❌ Not semantic --> <!-- Alt text for images --> <img src="chart.png" alt="Bar chart showing sales growth from 2020 to 2023"> <!-- ARIA labels --> <input type="text" aria-label="Search for products"> <!-- Labels for forms --> <label for="email">Email address</label> <input type="email" id="email"> <!-- Focus management --> <a href="#main-content">Skip to main content</a> <!-- Color contrast --> <!-- Use high contrast colors for text and backgrounds --> <!-- Keyboard navigation --> <!-- All interactive elements should be accessible via keyboard (tab) -->
♿
Accessibility Principles (POUR):
• Perceivable — Can users perceive the content?
• Operable — Can users operate the interface?
• Understandable — Can users understand it?
• Robust — Will it work with assistive technologies?
