Introduction

What is JavaScript?

⚡ JavaScript in Simple Words

JavaScript is a high-level, interpreted programming language that makes websites interactive. It's the "brain" of the web — it adds behavior to HTML and CSS.

Think of it like this: HTML is the skeleton, CSS is the skin, and JavaScript is the brain that makes everything work.

🏗️ HTML = Structure

Defines the content and structure of the page.

🎨 CSS = Presentation

Defines the visual appearance.

🧠 JavaScript = Behavior

Makes the page interactive — responds to clicks, changes content, communicates with servers, and more.

📜 A Brief History

  • 1995: Brendan Eich created JavaScript in 10 days while at Netscape
  • 1997: ECMAScript standard was created
  • 2009: ES5 introduced strict mode and JSON support
  • 2015: ES6 (ECMAScript 2015) — major update with classes, arrow functions, modules, and more
  • 2016+: Annual releases (ES7, ES8, ES9, etc.)
💡
JavaScript is now the most popular programming language in the world, running on over 98% of websites.

🌐 Where Does JavaScript Run?

  • Browsers — Chrome, Firefox, Edge, Safari (client-side)
  • Node.js — Server-side JavaScript
  • Mobile Apps — React Native, Ionic
  • Desktop Apps — Electron (VS Code, Slack)
  • IoT Devices — Smart home devices, robots

Async JavaScript

Callbacks, Promises, Async/Await

// Callback (old way) function fetchData(callback) { setTimeout(() => { callback("Data received"); }, 1000); } fetchData(function(data) { console.log(data); }); // Promise function fetchDataPromise() { return new Promise((resolve, reject) => { setTimeout(() => { resolve("Data received"); // reject("Error occurred"); }, 1000); }); } fetchDataPromise() .then(data => console.log(data)) .catch(error => console.error(error)) .finally(() => console.log("Done")); // Async/Await (ES8) async function getData() { try { let data = await fetchDataPromise(); console.log(data); } catch (error) { console.error(error); } } getData(); // Fetch API (AJAX) async function getUsers() { try { let response = await fetch("https://jsonplaceholder.typicode.com/users"); let data = await response.json(); console.log(data); } catch (error) { console.error("Error:", error); } }

Chapter 16

Advanced Topics

Closures

// A function with access to its outer scope function outerFunction(outer) { return function(inner) { console.log("Outer:", outer, "Inner:", inner); }; } const closure = outerFunction("outside"); closure("inside"); // Outer: outside Inner: inside // Practical: Private variables function counter() { let count = 0; return { increment: () => ++count, decrement: () => --count, getCount: () => count }; }

Higher-Order Functions

// Functions that take functions as arguments or return functions function operate(a, b, operation) { return operation(a, b); } const add = (a, b) => a + b; const multiply = (a, b) => a * b; console.log(operate(5, 3, add)); // 8 console.log(operate(5, 3, multiply)); // 15

this Keyword

// 'this' refers to the object that called the function const person = { name: "Akarsh", greet() { console.log("Hello, I'm", this.name); } }; person.greet(); // Hello, I'm Akarsh // Arrow functions don't bind 'this' const arrow = () => { console.log(this); // 'this' is from outer scope };

Prototype Chain

// Every object has a prototype const animal = { speak() { console.log("Speaking..."); } }; const dog = Object.create(animal); dog.bark = function() { console.log("Woof!"); }; dog.speak(); // "Speaking..." (from prototype) dog.bark(); // "Woof!" (own method)

Event Loop

// JavaScript is single-threaded with an event loop console.log("1"); setTimeout(() => console.log("2"), 0); console.log("3"); // Output: 1, 3, 2 (not 1, 2, 3) // Microtasks (Promises) run before macrotasks (setTimeout) console.log("1"); Promise.resolve().then(() => console.log("2")); setTimeout(() => console.log("3"), 0); console.log("4"); // Output: 1, 4, 2, 3
