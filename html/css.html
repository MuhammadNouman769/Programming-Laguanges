Introduction

What is CSS?

🎨 CSS in Simple Words

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML. It controls the look and feel of your web pages.

Think of CSS as the skin or clothing of a website — it adds colors, fonts, spacing, layout, animations, and makes everything visually appealing.

🏗️ HTML = Structure

Defines the content and structure of the page (the skeleton).

🎨 CSS = Presentation

Defines the visual appearance (the skin).

📝 How CSS Works

CSS works by selecting HTML elements and applying styles to them.

selector { property: value; } /* Example */ h1 { color: blue; font-size: 24px; } .button { background-color: #2563eb; color: white; padding: 10px 20px; border-radius: 8px; }

🔗 Ways to Add CSS

📄 Inline CSS

Applied directly to an element using the style attribute.

<h1 style="color: blue;">Hello</h1>

⚠️ Not recommended for large projects

📄 Internal CSS

Defined inside the <style> tag in the <head>.

<style> h1 { color: blue; } </style>

📄 External CSS (Best Practice)

CSS in a separate .css file linked to the HTML.

<!-- In HTML --> <link rel="stylesheet" href="style.css"> /* In style.css */ h1 { color: blue; }

✅ Reusable, cacheable, maintainable

Case Sensitivity

CSS is case-insensitive for property names and values, but it's good practice to use lowercase. IDs and classes are case-sensitive in HTML.

💡
Best Practice: Use lowercase for all CSS selectors, properties, and values. Use kebab-case for class names (e.g., .my-class).

Chapter 05

Box Model

Understanding the Box Model

Every element in CSS is a rectangular box with:

  • Content — The actual content (text, images)
  • Padding — Space between content and border
  • Border — Surrounds the padding (optional)
  • Margin — Space between the box and other elements
.box { width: 300px; height: 200px; padding: 20px; border: 2px solid #2563eb; margin: 20px; box-sizing: border-box; /* Includes padding and border in width/height */ }

Box Sizing

📦 Content Box (Default)

Width = content only. Padding and border add to the total width.

.box { box-sizing: content-box; width: 200px; padding: 20px; /* Total width = 240px */ }

📦 Border Box (Recommended)

Width = content + padding + border. Much easier to work with!

.box { box-sizing: border-box; width: 200px; padding: 20px; /* Total width = 200px */ }
💡
Best Practice: Apply box-sizing: border-box to all elements using the universal selector:
*, *::before, *::after { box-sizing: border-box; }

Margin & Padding Shorthand

/* All four sides */ margin: 20px; padding: 20px; /* Top & Bottom | Left & Right */ margin: 10px 20px; /* Top | Right | Bottom | Left (clockwise) */ margin: 10px 20px 30px 40px; /* Individual sides */ margin-top: 10px; margin-right: 20px; margin-bottom: 30px; margin-left: 40px;

Flexbox

Flexbox — One-Dimensional Layout

Flexbox is a layout model that allows items to align and distribute space within a container.

.flex-container { display: flex; flex-direction: row; /* row | row-reverse | column | column-reverse */ justify-content: center; /* Main axis alignment */ align-items: center; /* Cross axis alignment */ flex-wrap: wrap; /* Allow items to wrap */ gap: 16px; /* Space between items */ } .flex-item { flex: 1; /* Grow to fill space */ flex: 1 1 200px; /* flex-grow flex-shrink flex-basis */ align-self: center; /* Override align-items */ order: 2; /* Change visual order */ }

CSS Grid

Grid — Two-Dimensional Layout

CSS Grid is a powerful layout system for creating complex two-dimensional layouts.

.grid-container { display: grid; grid-template-columns: 200px 1fr 200px; grid-template-rows: auto 1fr auto; grid-template-areas: "header header header" "sidebar main main" "footer footer footer"; gap: 16px; } .grid-item { grid-column: 1 / 3; /* Span 2 columns */ grid-row: 1 / 2; } /* Using grid-area with named areas */ .header { grid-area: header; } .sidebar { grid-area: sidebar; } .main { grid-area: main; } .footer { grid-area: footer; }

Grid Units

Transitions & Animations

Transitions

Transitions allow smooth changes between property values.

.transition-example { background-color: #2563eb; transform: scale(1); transition: all 0.3s ease-in-out; } .transition-example:hover { background-color: #7c3aed; transform: scale(1.1); } /* Transition shorthand: property duration timing-function delay */ .custom-transition { transition: background-color 0.3s ease 0s, transform 0.5s ease-in-out 0.1s; }

Transition Timing Functions

FunctionDescription
easeSlow start, fast middle, slow end (default)
linearConstant speed
ease-inSlow start, fast end
ease-outFast start, slow end
ease-in-outSlow start and end
cubic-bezier(n,n,n,n)Custom curve

Animations

Animations provide more control than transitions with keyframes.

@keyframes slide-in { 0% { transform: translateX(-100px); opacity: 0; } 100% { transform: translateX(0); opacity: 1; } } .animated-element { animation: slide-in 1s ease-in-out forwards; /* name duration timing-function fill-mode */ } /* Animation properties */ .full-animation { animation-name: slide-in; animation-duration: 1s; animation-timing-function: ease-in-out; animation-delay: 0.5s; animation-iteration-count: infinite; animation-direction: alternate; animation-fill-mode: forwards; }

Chapter 10

Responsive Design

Media Queries

Media queries allow you to apply different styles based on screen size, device type, or other conditions.

/* Mobile First Approach */ .container { display: block; padding: 16px; } /* Tablet */ @media (min-width: 768px) { .container { display: flex; padding: 24px; } } /* Desktop */ @media (min-width: 1024px) { .container { max-width: 1200px; margin: 0 auto; padding: 32px; } } /* Print Styles */ @media print { .no-print { display: none; } }

Common Breakpoints

DeviceWidthBreakpoint
Mobile< 768pxSmall
Tablet768px - 1024pxMedium
Desktop> 1024pxLarge
Large Desktop> 1440pxXL

Responsive Units

/* Viewport units */ .full-height { height: 100vh; /* 100% of viewport height */ } .full-width { width: 100vw; /* 100% of viewport width */ } /* Relative units */ .relative-text { font-size: 1.2rem; /* Relative to root font size */ font-size: 1.2em; /* Relative to parent font size */ padding: 2%; /* Relative to parent width */ }
💡
Mobile First: Design for mobile screens first, then add styles for larger screens. This is the industry standard approach.
Chapter 11

Pseudo-Classes & Pseudo-Elements

Pseudo-Classes

Pseudo-classes target elements in a specific state.

/* Link states */ a:link { color: #2563eb; } /* Unvisited link */ a:visited { color: #7c3aed; } /* Visited link */ a:hover { color: #dc2626; } /* Hovered link */ a:active { color: #0891b2; } /* Active link */ /* Form states */ input:focus { border-color: #2563eb; outline: 2px solid rgba(37, 99, 235, 0.3); } input:disabled { background-color: #f1f5f9; opacity: 0.6; } input:checked { background-color: #2563eb; } /* Structural pseudo-classes */ li:first-child { font-weight: bold; } li:last-child { border-bottom: none; } li:nth-child(odd) { background: #f1f5f9; } li:nth-child(3n) { background: #dbeafe; }

Pseudo-Elements

Pseudo-elements target specific parts of an element.

p::first-line { font-weight: bold; color: #2563eb; } p::first-letter { font-size: 2em; font-weight: bold; color: #7c3aed; } p::before { content: "✨ "; font-size: 1.2em; } p::after { content: " ✨"; font-size: 1.2em; } /* Selection */ ::selection { background: #2563eb; color: white; }

Chapter 12

CSS Variables

Custom Properties (CSS Variables)

CSS variables allow you to reuse values throughout your stylesheet.

:root { /* Global variables */ --primary-color: #2563eb; --secondary-color: #7c3aed; --font-family: 'Segoe UI', sans-serif; --spacing: 16px; --border-radius: 8px; } .button { background-color: var(--primary-color); color: white; padding: var(--spacing); border-radius: var(--border-radius); font-family: var(--font-family); transition: all 0.3s ease; } .button:hover { background-color: var(--secondary-color); } /* Override in a specific component */ .dark-theme { --primary-color: #1e293b; --secondary-color: #0f172a; }

Benefits of CSS Variables

  • Reusability: Define once, use everywhere
  • Maintainability: Change one value, update everywhere
  • Dynamic: Can be changed with JavaScript
  • Theming: Easy to implement dark/light modes
/* Using variables with JavaScript */ <script> document.documentElement.style.setProperty('--primary-color', '#dc2626'); </script> /* Fallback values */ .element { color: var(--custom-color, #2563eb); /* If --custom-color is not set, use #2563eb */ }

CSS Best Practices

  • Use CSS variables for theming and reusability
  • Mobile first — design for mobile then enhance
  • Use classes instead of IDs for styling
  • Keep specificity low — avoid !important
  • Use Flexbox and Grid for modern layouts
  • Minify CSS for production
  • Use CSS preprocessors (Sass, Less) for larger projects
