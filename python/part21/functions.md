# Part 21: Functions

Functions package a repeatable piece of work behind a clear name. A good
function accepts inputs, returns a result, and leaves printing and user input
to the `main()` function.

## Practice path

- `task1.py`: return the current time from a function.
- `task2.py`: return multiplication results as a list.
- `task3.py`: return formatted table lines.
- `task4.py`: return one complete table as text.
- `mini_project.py`: use several functions in a table generator.

## Function checklist

1. Give the function one focused responsibility.
2. Name parameters clearly and provide useful defaults where appropriate.
3. Return data from reusable functions instead of printing from them.
4. Put interactive code inside `main()` and protect it with the `__main__`
   check.
