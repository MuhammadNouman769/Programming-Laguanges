# Part 9: Conditional decisions

This part practices comparisons, grades, leap years, and positive/negative checks.

## Practice files

- `task1.py`: compare two values.
- `task2.py`: classify a grade.
- `task3.py`: test a leap year.
- `task4.py`: classify an integer.
- `mini_project.py`: produce a student result report.

Existing files contain interactive versions of these checks.

## Original lesson content

### `odd_even.py`
Uses the remainder operator to classify a number as odd or even.

### `negtive_positive.py`
Distinguishes positive, negative, and zero values.

### `grade_check.py`
Maps marks to a grade with descending `if` and `elif` ranges.

### `leap_year.py`
Checks divisibility by 400, or by 4 but not 100, to identify leap years.

### `3_number_comparision.py`
Compares three numbers and prints the greatest value.
