# Part 16: Operators

This part practices arithmetic, comparison, logical, assignment, and membership operators.

## Practice files

- `task1.py`: calculate arithmetic results.
- `task2.py`: compare values.
- `task3.py`: test membership.
- `task4.py`: apply a discount.
- `mini_project.py`: calculate a receipt.

`oprators.py` and `mini_project1.py` are the existing examples.

## Original lesson content

### `oprators.py`
Covers addition, subtraction, multiplication, true division, floor division, modulus, and exponentiation with literals and variables.

```python
a = 15
b = 4
print(a + b)
print(a // b)
print(a % b)
print(a ** b)
```

### `mini_project1.py`
Reads two floating-point numbers, offers seven operations, checks division-like operations for zero, and reports invalid choices. The runnable migrated implementation is in `mini_project.py`.
